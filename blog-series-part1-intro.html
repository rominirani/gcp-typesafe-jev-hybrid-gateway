Introduction: The "Everything Is a Chatbot" Trap

Over the last few years, Large Language Models (LLMs) like Gemini, GPT, and Claude have become superhuman at conversing with people, writing code, and synthesizing complex documents. Because they are so capable, software teams started dropping them straight into backend microservices, event pipelines, and routing gateways.

And almost immediately, engineering teams hit four brick walls in production:

  1. The Latency Wall: Humans are fine waiting 3 to 8 seconds for a chat response to stream in. Microservices, API gateways, and event streams are not. Autoregressively generating tokens one by one turns a snappy backend into a sluggish bottleneck.
  2. The Token Cost Multiplier: Generating 150 tokens of structured JSON requires running 150 sequential transformer forward passes. When you process millions of events per day, spending $0.01 to $0.03 per routine triage check burns through cloud budgets.
  3. Schema Drift & Hallucinations: Even with JSON mode or constrained decoding, generative models occasionally hallucinate enum values, drop fields, or refuse benign prompts—causing downstream exceptions in strongly-typed code.
  4. Uncalibrated Overconfidence: Standard LLMs trained with RLHF (Reinforcement Learning from Human Feedback) are optimized to sound helpful and confident to human raters. They are notorious for being confidently wrong, making it hard for code to know when to act autonomously and when to escalate.
"LLMs produce words for people. Software automation doesn't need conversational strings—it needs fast, type-safe decisions with calibrated probabilities."

In this 5-part hands-on engineering series, we are going to build a production-grade Hybrid AI Architecture on Google Cloud. Instead of sending every single request to a heavy generative model, we will decouple fast, reflexive classification (System 1) from deep generative reasoning (System 2).

1. Meet Jev: Machine-Native "System 1" Intelligence

To solve the reflex side of our architecture, we use Jev, the first public model from TypeSafe AI (typesafe.ai), founded by former OpenAI researcher Diogo Almeida.

Where Do the Names "System One" and "Jev" Come From?

  • System One Models: Inspired by Daniel Kahneman’s book Thinking, Fast and Slow, which contrasts fast, automatic, intuitive System 1 thinking with slow, deliberate System 2 reasoning. While frontier LLMs and reasoning models focus on System 2 deliberation, Jev is built specifically for high-speed System 1 software decisions.
  • Jev (The Jevons Paradox): Named after the 19th-century economist William Stanley Jevons, who observed that when technological efficiency makes a resource drastically cheaper (as the steam engine did for coal), total consumption doesn't fall—it explodes by orders of magnitude. When machine decisions drop by 100x in latency and 400x in cost, developers can embed intelligence into every if-statement and event loop.

How Jev Differs from Traditional LLMs

Jev is not a smaller LLM or a wrapper around JSON mode. It uses a dedicated architecture, a parallel sampler, and a novel training objective called RLCD (Reinforcement Learning for Calibrated Decisions):

Capability Traditional Frontier LLMs (System 2) TypeSafe Jev (System 1)
Training Objective RLHF / RLVR (human preference & chat) RLCD (Reinforcement Learning for Calibrated Decisions)
Outputs Autoregressive strings (token-by-token) Typed structured values (Enums, Booleans, Probabilities)
Sampling Mechanism Sequential (N forward passes for N tokens) Parallel (all decision probabilities in a single pass)
Type Errors / Hallucinations Possible (JSON syntax failures, schema drift) Mathematically 0% (bound to predefined schema)
Confidence Calibration Often overconfident / uncalibrated Epistemically Calibrated (90% confidence ≈ 90% accuracy)
End-to-End Latency 1,500 ms – 15,000 ms+ 40 ms – 100 ms
Pricing $0.20 – $10.00 / MTok + output token fees $0.042 / MTok ($42 / Billion tokens); Output tokens FREE

3. Hands-On: Calling Jev Directly in Python

Before deploying anything to Google Cloud, let's look at how simple it is to call TypeSafe Jev from Python via POST https://api.typesafe.ai/v1/systemone (or using the official typesafe-sdk package). You pass your unstructured input (state) alongside a dictionary of questions using TypeSafe's three decision primitives—choice (categorical enums), score (ordinal severity scales), and noul (calibrated boolean judgments):

#!/usr/bin/env python3
"""Minimal Python Quickstart: Calling TypeSafe Jev (/v1/systemone) via HTTP."""

import os
import json
import time
import urllib.request

TYPESAFE_API_KEY = os.environ["TYPESAFE_API_KEY"]
TYPESAFE_API_URL = "https://api.typesafe.ai/v1/systemone"

payload = {
    "state": "Where is my package #8942? Has it shipped yet?",
    "model": "jev-latest",
    "questions": {
        "category": {
            "type": "choice",
            "instructions": "Classify the primary intent of this customer support inquiry.",
            "criteria": {
                "ORDER_STATUS": "Tracking an order, shipment, or delivery date",
                "REFUND_REQUEST": "Requesting a refund or billing credit",
                "SUBSCRIPTION_CANCEL": "Canceling a recurring subscription",
                "COMPLEX_TROUBLESHOOTING": "Complex technical outage or multi-part legal question",
            },
        },
        "urgency": {
            "type": "score",
            "instructions": "Rate the operational urgency of this request.",
            "criteria": ["Low", "Medium", "High", "Critical"],
        },
        "can_auto_resolve": {
            "type": "noul",
            "instructions": "Can this request be resolved deterministically by an automated backend webhook?",
            "criteria": {
                "true": "Routine deterministic request that can be handled automatically",
                "false": "Ambiguous or critical request requiring human or LLM reasoning",
            },
        },
    },
}

start = time.perf_counter()
req = urllib.request.Request(
    TYPESAFE_API_URL,
    data=json.dumps(payload).encode("utf-8"),
    headers={
        "Authorization": f"Bearer {TYPESAFE_API_KEY}",
        "Content-Type": "application/json",
    },
    method="POST",
)

with urllib.request.urlopen(req, timeout=10.0) as resp:
    result = json.loads(resp.read().decode("utf-8"))

latency_ms = (time.perf_counter() - start) * 1000
print(f"Latency: {latency_ms:.1f} ms")
print(json.dumps(result, indent=2))

Running our standalone script (export TYPESAFE_API_KEY="your_key" && python3 scripts/quickstart_jev.py) produces the following output:

⚡ Latency:       75.2 ms
🤖 Model:         jev-1.13.0
🎯 Category:      ORDER_STATUS
🔥 Urgency:       LOW (score=0.00)
📊 Confidence:    98.5% (RLCD Calibrated)
🤖 Auto-Resolve:  True (noul=0.970)

Notice three crucial details in this output:

  • Full Probability Distribution in One Pass: You get the exact probability breakdown across all enum values simultaneously.
  • Epistemic Honesty: The confidence score (0.985) and noul score (0.970) are calibrated via RLCD, meaning your code can trust numerical thresholds like if confidence >= 0.90.
  • Zero String Parsing: There is no markdown wrapper or conversational preamble to strip out.

4. Stage 01 Walkthrough: Deploying a Standalone Jev Classifier on Cloud Run

Now let's take our first baby step on Google Cloud: wrapping Jev into a clean, serverless Cloud Run microservice (01-basic-classifier/) backed by Google Cloud Secret Manager.

4.1 The Microservice Code (01-basic-classifier/main.py)

We use FastAPI and Pydantic to expose a POST /classify endpoint and a GET /health liveness check (note: on Cloud Run, we use /health rather than /healthz since the Google Front End reserves /healthz). The service strictly requires TYPESAFE_API_KEY (mounted securely from Secret Manager) and calls https://api.typesafe.ai/v1/systemone directly:

"""Minimal Standalone Jev Classification Microservice on Google Cloud Run."""

import os
import time
import json
import urllib.request
from enum import Enum
from typing import Dict
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field

app = FastAPI(
    title="Jev Standalone Classifier on Cloud Run",
    description="Baby step 1: Deploying TypeSafe Jev System 1 intelligence to Cloud Run.",
    version="1.0.0",
)

TYPESAFE_API_KEY = os.getenv("TYPESAFE_API_KEY", "").strip()
TYPESAFE_API_URL = os.getenv("TYPESAFE_API_URL", "https://api.typesafe.ai/v1/systemone")
TYPESAFE_MODEL = os.getenv("TYPESAFE_MODEL", "jev-latest")


class ClassificationRequest(BaseModel):
    query: str = Field(..., description="Unstructured user inquiry or event string.")


class CategoryEnum(str, Enum):
    ORDER_STATUS = "ORDER_STATUS"
    REFUND_REQUEST = "REFUND_REQUEST"
    SUBSCRIPTION_CANCEL = "SUBSCRIPTION_CANCEL"
    AUTHENTICATION_ISSUE = "AUTHENTICATION_ISSUE"
    COMPLEX_TROUBLESHOOTING = "COMPLEX_TROUBLESHOOTING"
    UNKNOWN = "UNKNOWN"


class ClassificationResponse(BaseModel):
    query: str
    model: str
    category: str
    urgency: str
    calibrated_confidence: float
    can_auto_resolve: bool
    suggested_action: str
    probabilities: Dict[str, float]
    latency_ms: float
    platform: str = "Google Cloud Run"


@app.post("/classify", response_model=ClassificationResponse)
def classify_text(req: ClassificationRequest):
    """Classify input text using TypeSafe Jev (/v1/systemone) with strict typing and calibrated confidence."""
    if not TYPESAFE_API_KEY:
        raise HTTPException(
            status_code=500,
            detail="TYPESAFE_API_KEY environment variable is required.",
        )

    start_time = time.perf_counter()
    payload = {
        "state": req.query,
        "model": TYPESAFE_MODEL,
        "questions": {
            "category": {
                "type": "choice",
                "instructions": "Classify the primary intent of this customer support inquiry.",
                "criteria": CATEGORY_CRITERIA,
            },
            "urgency": {
                "type": "score",
                "instructions": "Rate the operational urgency of this inquiry.",
                "criteria": ["Low", "Medium", "High", "Critical"],
            },
            "can_auto_resolve": {
                "type": "noul",
                "instructions": "Can this inquiry be resolved deterministically by an automated backend webhook?",
                "criteria": {
                    "true": "Routine deterministic request that can be handled automatically",
                    "false": "Ambiguous or critical request requiring human or LLM reasoning",
                },
            },
        },
    }

    http_req = urllib.request.Request(
        TYPESAFE_API_URL,
        data=json.dumps(payload).encode("utf-8"),
        headers={
            "Authorization": f"Bearer {TYPESAFE_API_KEY}",
            "Content-Type": "application/json",
        },
        method="POST",
    )
    with urllib.request.urlopen(http_req, timeout=10.0) as resp:
        data = json.loads(resp.read().decode("utf-8"))

    latency_ms = (time.perf_counter() - start_time) * 1000
    answers = data.get("answers", {})
    cat_ans = answers.get("category", {})
    urg_ans = answers.get("urgency", {})
    auto_ans = answers.get("can_auto_resolve", {})

    chosen_cat = cat_ans.get("choice", "UNKNOWN")
    confidence = float(cat_ans.get("confidence", 0.0))
    can_auto_resolve = float(auto_ans.get("noul", 0.0)) >= 0.5

    return ClassificationResponse(
        query=req.query,
        model=data.get("model", TYPESAFE_MODEL),
        category=chosen_cat,
        urgency=_score_to_urgency(float(urg_ans.get("score", 0.33))),
        calibrated_confidence=round(confidence, 4),
        can_auto_resolve=can_auto_resolve,
        suggested_action=ACTION_MAP.get(chosen_cat, "ESCALATE_TO_GEMINI"),
        probabilities=cat_ans.get("probabilities", {}),
        latency_ms=round(latency_ms, 2),
    )

4.2 Storing the API Key in Secret Manager & Deploying to Cloud Run

First, store your TypeSafe API key in Google Cloud Secret Manager, and then deploy the service from source with --set-secrets:

# 1. Store your TypeSafe API key in Secret Manager
echo -n "YOUR_TYPESAFE_API_KEY" | gcloud secrets create typesafe-api-key \
  --replication-policy="automatic" \
  --project=YOUR_PROJECT_ID \
  --data-file=-

# 2. Deploy to Cloud Run with Secret Manager binding
gcloud run deploy jev-basic-classifier \
  --source=01-basic-classifier \
  --region=us-central1 \
  --project=YOUR_PROJECT_ID \
  --allow-unauthenticated \
  --min-instances=0 \
  --max-instances=5 \
  --memory=512Mi \
  --cpu=1 \
  --timeout=30s \
  --set-secrets="TYPESAFE_API_KEY=typesafe-api-key:latest"
